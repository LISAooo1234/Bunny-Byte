│                                                                                     │

│   │  STEP 1: 入口层                                                              │  │

│   │    (初始化 SessionStore / RunStore / Memory / Skills / Engine / WorkerMgr)   │  │
│   └──────────────────────────────────┬──────────────────────────────────────────┘  │
│                                      ▼                                             │

│   │  }                                                                           │  │

│                                      ▼                                             │
│   ┌─────────────────────────────────────────────────────────────────────────────┐  │
│   │  STEP 3: Engine.run_turn("找出测试失败的根因")                                │  │
│   │                                                                              │  │
│   │  3a. ContextManager.assemble(user_message)                                   │  │
│   │      → 拼接 prefix + memory + skills + relevant_memory + history + request   │  │
│   │                                                                              │  │
│   │  3b. complete_model_with_deltas(prompt, tools=native_tool_specs)             │  │
│   │      → 独立线程 → HTTP POST → provider endpoint                              │  │

│   │                                                                              │  │

│   │                                                                              │  │
│   │  3e. tool_executor.run_tool("run_shell", args)                               │  │
│   │      → ① 参数校验 ✓                                                         │  │
│   │      → ② 重复检测 ✓  (首次, 通过)                                            │  │
│   │      → ③ Permission.check() → approval_policy → 询问用户                     │  │
│   │      → ④ ToolPolicy.check() → 非搜索命令, 非 git, 通过                       │  │
│   │      → ⑤ SandboxChecker → 不在未知命令列表 → 直接 subprocess.run            │  │

│   │                                                                              │  │

│   └─────────────────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────────────────┘
